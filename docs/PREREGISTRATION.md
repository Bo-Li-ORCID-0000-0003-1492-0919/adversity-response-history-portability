# Preregistration

The extension protocol is linked to [OSF zgeb3](https://osf.io/zgeb3/). It covers recurrent caregiving, prediction from multiple prior acute responses, and the secondary recency comparison. The registration was completed before coefficients or predictive-performance estimates for these extensions were calculated.

The original cross-adversity analyses and the item-level measurement analyses were completed before this registration and are not described as preregistered. The protocol used for the extension is included as `registration/preregistration.pdf`.

A separate implementation note was finalized locally before model fitting but was not attached to the OSF registration. This distinction is summarized in `registration/REGISTRATION_SCOPE.md`.

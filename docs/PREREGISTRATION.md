# Preregistration

The extension protocol is linked to [OSF zgeb3](https://osf.io/zgeb3/). The author confirmed that the included v2 PDF is the registered attachment. It covers recurrent caregiving, prediction from multiple prior acute responses, and a secondary recency comparison. This author-supplied registration identity is distinct from independent retrieval of the immutable OSF attachment inventory, which was not available through anonymous access during the 7 September 2026 audit. Local records place the implementation note before the recorded extension fit start; they do not independently establish the time of first human viewing of results.

The original cross-adversity analyses and the item-level measurement analyses were completed before this registration and are not described as preregistered. The protocol used for the extension is included as `registration/preregistration.pdf`.

A separate implementation note was finalized locally before model fitting but was not attached to the OSF registration. This distinction is summarized in `registration/REGISTRATION_SCOPE.md`.

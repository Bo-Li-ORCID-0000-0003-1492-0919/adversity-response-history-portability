# Methods and post-result reproduction

This document accompanies v1.0.3. The v1.0.2 GitHub/Zenodo archive is retained as a separate historical version. The revised Extended Data displays are integrated here; the original aggregate source values remain unchanged.

## Analysis-specific operations

- Descriptive trajectories used cohort pre1 means and sample standard deviations across collapsed primary-event episodes before the isolated-episode restriction. A person could contribute multiple episodes. The U/E models included participant and episode random intercepts. E added time-by-event interactions. Descriptive intervals resampled person-level GLS contributions, re-solving fixed effects with covariance parameters held fixed.
- Earlier full-scale U/E, P, B/ANCOVA and alternative-representation prediction scaled psychological scores using primary-event episodes belonging to outer-training people; temporal validation also restricted reference episode dates to the cutoff. This was not the unique-target pre1 reference used in the registered extension. Split-half prediction used separate earlier-predictor-form and later-outcome-form training scales. Psychological scale standard deviations used ddof=1; matrix conditioning was separate.
- Earlier temporal splits used the floor of 0.70N as a one-based observed-date order statistic. Registered extension splits used the ceiling. Date ties entered training. Later observations from a person already in training were excluded from testing. The preserved analysis branches and sample definitions were not unified after seeing results.
- Predictive comparison bootstraps resampled paired held-out participant predictions, with models and folds fixed. The split-half directions shared participant resampling weights; direction-specific increments were averaged equally. Ridge sensitivities retained outer-training transformations during inner tuning. No outer-test observations contributed to fitted transformations.
- U/E density used mixed-model training residual variances, averaged across folds with held-out row-count weights. Earlier P analyses similarly averaged supplied training OLS residual variances. B/ANCOVA, representations and split-half routines retained each observation's fold-specific training OLS residual variance. The registered extension used each model's own outer-training RSS/n and treated invalid variance as not estimable.
- Observation weights and complete-time-point checks concerned descriptive persistence summaries, not all predictive comparisons. Official survey weights were not applied. Observation-model covariates included median-filled health/marital codes and zero-filled absent prior history plus a no-history indicator. Mental-health outcomes/items were not imputed. The historical logistic implementation used a small always-on 1e-8 coefficient-squared numerical term, not the stronger conditional C=1 penalty specified as a fallback. All four observation models converged in the replay; a linear-programming separation diagnostic found no separating direction. Thus the stronger fallback was not required in those fits.

## Reproduction performed on 7 September 2026

The original analysis sources, input files, sample selections, seeds, fold rules, numerical algorithms and bootstrap rules were retained. Instrumented copies saved training scales, memberships, fitted objects, held-out predictions and bootstrap draws inside the licensed local environment. The replay covered 2,992 measurement/adjudication result rows and 501 earlier confirmatory, trajectory and weighting result rows. Numeric comparisons used absolute tolerance 1e-10 and relative tolerance 1e-8, and separately checked four-decimal displays. All comparisons passed; no displayed estimate or interval changed.

The measurement replay made 256,856 metric calls and the earlier confirmatory replay made 38,058 metric calls. None supplied invalid training variance. Consequently the historical evaluation-MSE density fallback was not invoked in these replays. This check also reproduced intervals whose successful-resample selection depended on finite predictive density. The participant-level artifacts are not part of this public package.

These are new post-result reproduction records, not recovered contemporaneous fit files or new preregistered analyses. Exact reproduction supports the reported numerical outputs; it does not establish when a person first viewed results. Earlier file-hash identities and registration timestamps must be supported by their own evidence. The local case-lock record named an engine hash for which no executable copy was recovered; the later fit-start hash matches the saved running engine. This provenance gap is retained, not retrospectively repaired with a fabricated historical file.

## Prospective safety changes

The two early metric functions now raise a clear error for invalid training variance instead of substituting evaluation MSE. Calculations with valid variances are identical. The registered extension's pre-existing NaN/not-estimable rule is untouched. The descriptive bootstrap retry limit now also covers singular matrix failures. Synthetic-data tests cover these branches. These guards do not change the preserved scientific results.

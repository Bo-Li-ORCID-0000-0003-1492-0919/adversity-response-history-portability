# Results provenance

The CSV files in `source_data/main/` and `source_data/extended_data/` were exported from the aggregate analysis results in `source_data/analysis_outputs/`. They include a repository-relative source path, source row and numeric fields used to check each display. They do not contain participant-level records.

The public XLSX workbooks correspond to the source-data files supplied with the manuscript. One metadata label was corrected before release: HRS in Figure 1 is described as an independent conceptual replication. No sample size, estimate or confidence interval changed.

The scripts in `src/analysis/` are the analysis files retained from the final project record. The scripts in `src/figures/` use repository-relative aggregate inputs and caller-selected output folders. The PDFs in `expected_outputs/` are the final submission figures used for comparison.
